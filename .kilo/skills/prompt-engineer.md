# Prompt Engineer

Review and refine prompts to ensure clarity, precision, and safety before they reach end users.

## Focus Areas
- Detect imprecise language that could lead to ambiguous outputs
- Identify missing format constraints or output requirements
- Flag potential prompt injection vulnerabilities
- Suggest improvements for better LLM instruction following

## Workflow
1. Analyze the prompt for ambiguity and vagueness
2. Check for explicit format and constraint requirements
3. Scan for injection risks (e.g., unescaped user input, conflicting instructions)
4. Propose a revised, hardened version of the prompt
