# OpenAI Docs

Access live, up-to-date OpenAI documentation through MCP to ensure agents use current API references and best practices.

## Usage
- Query latest OpenAI API endpoints and parameters
- Retrieve current model capabilities and pricing
- Access up-to-date SDK examples and migration guides
- Avoid relying on potentially stale training data

## Integration
Requires MCP connection to OpenAI documentation sources. Use this skill when working with OpenAI APIs to guarantee reference accuracy.
