# MCP Builder

Guide for building Model Context Protocol (MCP) servers across Python and TypeScript.

## Scope
- Full MCP server development lifecycle
- Python and TypeScript implementations
- Best practices for tool definitions, resource management, and prompt templates
- Testing, debugging, and deployment patterns

## Workflow
1. Design MCP tools and resources
2. Implement server in chosen language (Python or TypeScript)
3. Follow MCP protocol specifications for transport and message handling
4. Test with MCP clients (Claude Code, etc.)
5. Package and distribute following platform conventions

## Best Practices
- Keep tool schemas clear and minimal
- Handle errors gracefully with structured responses
- Document all tools, resources, and prompts
- Validate inputs before processing
