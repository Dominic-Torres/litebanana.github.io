# Skill Creator

Guide for designing, building, and evaluating custom skills with iterative improvement.

## Workflow
1. Define the skill's purpose and scope
2. Draft initial instructions and examples
3. Implement variance analysis to measure consistency across inputs
4. Iterate based on evaluation results
5. Refine instructions to reduce output variance and improve reliability

## Key Principles
- Start with a clear, narrow scope
- Include concrete examples in the skill definition
- Use variance analysis to identify instruction gaps
- Continuously evaluate and refine
